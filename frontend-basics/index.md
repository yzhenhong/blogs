# 前端基础

前端基础专题整理浏览器页面开发中最常用的三部分知识：CSS 负责布局与视觉表现，JavaScript 负责运行时逻辑，TypeScript 在 JavaScript 之上补充静态类型和工程约束。

## 专题入口

| 专题 | 主要内容 | 入口 |
| --- | --- | --- |
| CSS | 选择器、盒模型、布局、响应式、动画 | [CSS 完全指南](/frontend-basics/css/index.md) |
| JavaScript | 类型、函数、对象、异步、模块与运行机制 | [JavaScript 完全指南](/frontend-basics/js/index.md) |
| TypeScript | 类型系统、泛型、工程配置与类型设计 | [TypeScript 完全指南](/frontend-basics/ts/index.md) |

## 推荐顺序

1. 先掌握 HTML/CSS 布局和浏览器基本渲染方式。
2. 学习 JavaScript 类型、作用域、函数、对象和异步流程。
3. 在能够独立完成 JavaScript 项目后引入 TypeScript。
4. 结合真实页面练习网络请求、状态管理、错误处理和性能分析。
