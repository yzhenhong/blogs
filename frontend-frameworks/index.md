# 前端框架

本专题覆盖 Vue、React 以及建立在它们之上的 Nuxt 和 Next.js。Vue 与 React 主要解决组件化界面和客户端状态，Nuxt 与 Next.js 进一步提供路由、服务端渲染、数据获取、服务端能力和部署约定。

## 专题入口

| 技术 | 定位 | 入口 |
| --- | --- | --- |
| Vue | 渐进式组件框架 | [Vue 完全指南](/frontend-frameworks/vue/index.md) |
| React | 声明式 UI 库 | [React 完全指南](/frontend-frameworks/react/index.md) |
| Nuxt | Vue 全栈框架 | [Nuxt.js 完全指南](/frontend-frameworks/nuxt/index.md) |
| Next.js | React 全栈框架 | [Next.js 完全指南](/frontend-frameworks/next/index.md) |

## 如何选择

| 情况 | 优先评估 |
| --- | --- |
| 团队熟悉 Vue，需要渐进式接入 | Vue |
| 团队熟悉 React，需要自由组合生态 | React |
| Vue 项目需要 SSR、SSG、服务端 API 和约定式路由 | Nuxt |
| React 项目需要 SSR、静态生成、服务端组件和全栈能力 | Next.js |

框架选型还应通过真实原型验证团队经验、第三方组件、部署平台、SEO、性能和长期维护成本，不能只比较语法偏好。

## 推荐学习顺序

1. 先完成 [JavaScript](/frontend-basics/js/index.md) 和 [TypeScript](/frontend-basics/ts/index.md) 基础。
2. 选择 Vue 或 React，理解组件、状态、生命周期和路由。
3. 再学习对应的 Nuxt 或 Next.js，重点理解服务端与浏览器边界。
4. 最后补充测试、性能、安全、缓存和部署实践。
